# Java Practice

A collection of Java practice programs covering core Java concepts, object-oriented programming, collections, exception handling, Java 8 features, multithreading, and JDBC.

## Topics Covered

- Java Basics
- Arrays and Strings
- Object-Oriented Programming
- Exception Handling
- Collections Framework
- Java 8 Features
- Multithreading
- JDBC

## Repository Structure

```text
Java-Practice/
├── 01-Basics/
├── 02-Arrays-And-Strings/
├── 03-OOP/
├── 04-Exception-Handling/
├── 05-Collections/
├── 06-Java-8-Features/
├── 07-Multithreading/
└── 08-JDBC/
```

## Purpose

This repository contains practical Java programs for strengthening programming fundamentals, problem-solving skills, and interview preparation.

## Requirements

- Java JDK 17 or later
- Any Java-compatible IDE or editor
